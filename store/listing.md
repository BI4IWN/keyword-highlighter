# Chrome Web Store 商店信息（直接复制到后台对应输入框）

## 名称（Name，≤45 字符）

关键词高亮助手

## 简短说明（Short description，≤132 字符）

自定义关键词，在网页中自动高亮显示。支持批量颜色、大小写、iframe 与动态内容监听，纯本地运行。

## 详细说明（Detailed description）

自定义关键词，在所有网页中自动高亮显示，阅读、检索、盯文案更省眼。

✨ 功能特性
・关键词管理：回车添加，支持逗号批量添加，最多 100 个
・默认黄色高亮，也可逐词自定义颜色
・批量设置颜色：预设色板一键应用，或自定义颜色应用到全部
・大小写匹配：默认不区分，可切换精确匹配
・iframe 支持：网页内嵌框架中的关键词同样高亮
・动态内容监听：SPA、无限滚动、流式输出等新内容自动扫描
・自动生效：安装/更新后已打开的页面自动补注入，无需逐个刷新
・角标计数：工具栏显示当前页命中数量
・安全排除：输入框、编辑器、代码块不做处理，不破坏页面功能

🔒 隐私
・不收集任何数据，无任何远程请求，全部本地运行
・配置仅存于浏览器，登录浏览器账号可在设备间同步

📌 使用
1. 点击工具栏图标打开面板
2. 输入关键词回车即可（多个词用逗号分隔）
3. 在底部用色板批量调整颜色
