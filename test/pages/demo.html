为什么你需要一款关键词高亮工具

每天我们在 Chrome 和 Edge 里要读大量的网页：技术文档、新闻、竞品文案。想盯住的词散落在长文里，来回扫读非常低效。高亮工具把你的注意力关键词自动标出来，一眼就能定位。

以「关键词高亮助手」为例：按 回车 添加 Chrome、高亮、Edge 等关键词，所有页面立即生效；还可以用色板批量设置颜色，比如把产品名标成蓝色、风险词标成红色。

提示：动态加载的内容（无限滚动、聊天气泡）也会被自动扫描高亮，无需手动刷新。

对开发者而言，阅读 API 文档时高亮函数名和参数尤其好用；fetch、webhook 这类词一秒现形，代码块默认不被打扰。

配置保存在浏览器里，登录账号后可在多台设备间同步，公司电脑和家里笔记本看到的效果完全一致。
